# 🌦️ Weather API Client

A beginner-friendly Python backend project that fetches live weather information using an online weather API.

This project was built to learn:

* API calls
* JSON processing
* Exception handling
* Logging
* Modular coding
* Git & GitHub workflow

---

# 🚀 Features

✅ Fetch live weather data
✅ Displays:

* Temperature
* Humidity
* Weather condition

✅ Uses REST API
✅ Handles errors gracefully
✅ Uses logging system
✅ Modular project structure
✅ Config-based setup

---

# 🛠️ Technologies Used

* Python 3

* REST API

# ⚙️ Setup Instructions

## 1️⃣ Clone Repository

```bash id="jlwm111"
git clone https://github.com/shakee19/weather-api-client.git
```

---

## 2️⃣ Move into Project Folder

```bash id="jlwm112"
cd weather-api-client
```

---

## 3️⃣ Create Virtual Environment

```bash id="jlwm113"
python3 -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Mac/Linux

```bash id="jlwm114"
source venv/bin/activate
```

### Windows

```bash id="jlwm115"
venv\Scripts\activate
```

---

## 5️⃣ Install Dependencies

```bash id="jlwm116"
pip3 install -r requirements.txt
```

---

## 6️⃣ Run Project

```bash id="jlwm117"
python3 main.py
```
